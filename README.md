# Lotofácil Engine

Engine desenvolvida em Python para geração de jogos equilibrados da Lotofácil.

## Regras implementadas

- Pares / Ímpares
- Fibonacci
- Moldura
- Centro
- Primos
- Múltiplos de 3
- Linhas
- Colunas

## Em desenvolvimento

- Cruz
- X
- Quadrantes
- Refatoração
- Geração automática de múltiplos jogos
